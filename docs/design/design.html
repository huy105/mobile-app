Canteen App - UI Design Reference

Mockup HTML cho Antigravity vẽ lại bằng Jetpack Compose + Material 3. Mọi kích thước tính theo dp (1px trong file này = 1dp). Phone frame 360 x 740dp, tablet căng tin 1024 x 620dp (landscape). Emoji chỉ là ảnh giữ chỗ: trong app thật dùng imageUrl với Coil, có placeholder. Phong cách: tươi sáng, ấm, bo góc lớn, nhiều khoảng trắng.

Font: Plus Jakarta Sans (Google Fonts, dùng androidx.compose.ui:ui-text-google-fonts). Shape: card 16dp, button 12dp, chip pill (full), bottom sheet 24dp, thumbnail 12dp. Spacing: 4 / 8 / 12 / 16 / 24dp, lề màn hình 16dp. Touch target tối thiểu 44dp (nút chính 48dp). Light theme là mặc định, không cần dark mode cho demo.

4. Quy tắc chung cho Compose

• Tạo ui/common/theme/ gồm Color.kt (token ở trên), Type.kt (Plus Jakarta Sans), Shape.kt, Theme.kt (lightColorScheme map từ token; luôn dùng light).
• Component dùng chung trong ui/common/: PrimaryButton, StatusTag(status), MenuItemCard, QuantityStepper, EmptyState(icon, text), LoadingBox, PinBox.
• StatusTag map: RECEIVED → infoContainer/info · PREPARING → secondaryContainer/#92400E · READY → successContainer/success · COMPLETED → surfaceVariant/onSurfaceVariant · CANCELLED → errorContainer/error.
• Mọi danh sách có 3 trạng thái: loading (CircularProgressIndicator giữa màn hình), rỗng (EmptyState), lỗi (Snackbar hoặc thẻ lỗi kèm nút Thử lại).
• Animation: chuyển bước stepper và đổi màu tag bằng animateColorAsState (200ms), không dùng animation nặng.
• Phát hiện thiết bị: vai trò CANTEEN dùng NavigationRail + layout rộng khi width >= 600dp, thu về NavigationBar nếu màn nhỏ. Vai trò STUDENT luôn dùng NavigationBar dưới cùng.
• Tiền VND định dạng "%,d".replace(',', '.') + "đ". Chuỗi hiển thị lấy từ strings.xml (tiếng Việt).
